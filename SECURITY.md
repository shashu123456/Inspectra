# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability in Inspectra itself, please report
it responsibly:

1. **Do not** open a public issue for security problems.
2. Use GitHub's **"Report a vulnerability"** (Security → Advisories) so the
   report stays private, or contact the maintainers through the repository's
   listed contact.
3. Include reproduction steps, affected version and impact assessment.

You can expect an initial response within 7 days and a fix or mitigation
plan within 30 days for accepted reports.

## Scope

In scope: the Inspectra codebase, its reports, and the data files it ships.

Out of scope: vulnerabilities in scanned targets. Inspectra is an
assessment tool; findings about a target belong to the target's owner.

## Safe Harbor

We consider good-faith research against your own instances of Inspectra to
be authorized and will not pursue legal action for responsible disclosure.
