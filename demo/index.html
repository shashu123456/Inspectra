How to run it yourself (CLI)

.venv\Scripts\inspectra scan example.com --format html
.venv\Scripts\inspectra scan 192.168.1.1:8443 --ports 80,443,8443
.venv\Scripts\inspectra scan example.com --skip-ports        # no Nmap needed
.venv\Scripts\python demo\server.py                          # this demo
